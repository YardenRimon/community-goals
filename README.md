# כלי לבחירת ואיחוד יעדים קהילתיים

פלטפורמת Web תומכת-הנחיה לניהול תהליכי בחירה ואיחוד של יעדים קהילתיים וארגוניים בשקיפות מלאה ובסנכרון זמן-אמת, כולל שימור ידע רב-שנתי במאגר מידע מובנה.

---

## מבנה התהליך באפליקציה (4 שלבים)

1. **שלב 1 – כתיבת יעדים אישיים:** הזנה פרטית בנייד של יעדים קונקרטיים (עריכה ומחיקה חופשית). כל יעד נשאר פרטי לכותבו עד שיבחר להציגו.
2. **שלב 2 – איחוד יעדים בקבוצה:** סבב שיתוף יעד-יעד בשולחן הקבוצתי לצמצום כפילויות ללא ויתור על יעדים (`הצעה לאיחוד יעדים` ← `יעד אחוד`).
3. **שלב 3 – הצבעה בקבוצה:** בחירה קומפקטית ודירוג בגרירה של 7 יעדים (`7` עד `1` נקודות), ניתוח תוצאות בשקיפות שמית מלאה וחישוב `חוזק היעד`, והעלאת 10 היעדים המובילים מכל שולחן.
4. **שלב 4 – איחוד יעדים בין הקבוצות:** שולחן עבודה לצוות המנחים לאיחוד יעדים דומים שעלו מהקבוצות השונות להפקת רשימת `היעדים האחודים` הסופית של האירוע וייצוא לאקסל.

---

## מבנה המאגר ותיעוד הפרויקט

* [`docs/SPECIFICATION_AND_PLAN.md`](./docs/SPECIFICATION_AND_PLAN.md) – **מסמך האפיון המלא ותכנית הפיתוח (Single Source of Truth)**: שפה עיצובית, מילון טרמינולוגיה ומיקרו-קופי, ניהול ארגונים ואירועים, שיוך לשולחנות ותפקידי מנחה (קוד + קישור + QR), לוגיקה עסקית ו-5 אבני הדרך לפיתוח.
* [`docs/DATABASE_SCHEMA.sql`](./docs/DATABASE_SCHEMA.sql) – **סכמת מסד הנתונים (`PostgreSQL / Supabase`)**: מבנה הטבלאות ועקרונות האבטחה והפרטיות (`Row-Level Security`).
* [`demo/index.html`](./demo/index.html) – אב-טיפוס אינטראקטיבי ראשוני להדגמת זרימת 4 השלבים.

## מחסנית טכנולוגית מתוכננת (MVP)

* **Frontend:** `React 19 + Vite + TypeScript + Tailwind CSS (RTL)` + `Lucide Icons` + `@dnd-kit`
* **Backend & Realtime Database:** `Supabase` (`PostgreSQL`, `Realtime WebSockets`, `Auth: Google OAuth + Email OTP`)
* **Deployment:** תואם מלא ל-`GitHub Pages` וכן ל-`Cloudflare Pages` / `Vercel`
